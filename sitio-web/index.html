Control de asistencia + verificación de uniforme

Registra la asistencia y confirma el uniforme, en el mismo paso.

Cada persona completa sus datos, se toma una foto y el sistema verifica automáticamente si lleva el uniforme correcto antes de marcar su asistencia como válida.

Cómo funciona

Tres pasos, sin instalar nada. Funciona desde cualquier navegador con cámara.

01

Completa sus datos

Nombres completos, apellidos y DNI, directamente desde el navegador.

02

Se toma una foto

La cámara del dispositivo captura una foto de frente, con el torso visible.

03

Verificación automática

El sistema revisa el color de la prenda. Si no cumple, la asistencia queda rechazada y se pide justificarla en administración.

Para quién es

Colegios e institutos

Control de uniforme diario de estudiantes al ingresar.

Empresas

Verificación de dress code en plantas, tiendas o turnos de atención.

Eventos y capacitaciones

Registro rápido de asistentes con evidencia fotográfica.
